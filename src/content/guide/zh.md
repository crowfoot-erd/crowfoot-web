Crowfoot 是一个在网页上绘制 ERD、与数据库互通并供团队协作的工具。本指南按实际工作的顺序说明：从创建第一个文档，到建立标准，再到应用到数据库。

![ERD 编辑器界面](/landing/editor-zh-light.webp)

下面的截图为韩语界面，正文中的菜单名称为中文界面的名称。

## 1. 开始使用

1. 使用 GitHub 或 Google 账号登录。
2. 创建**工作区**。工作区把文档、数据库连接、术语词典和域类型放在一起。建议每个团队或项目创建一个。
3. 在工作区的 **ERD** 标签页创建文档。有四种方式。

| 方式 | 适用场景 |
| --- | --- |
| 新建 ERD 文档 | 从空白画布开始绘制 |
| 导入 SQL | 已经有 `CREATE TABLE` 语句 |
| 从数据库导入 | 直接读取已有数据库的结构 |
| 从模板开始 | 从相近主题的示例开始 |

创建文档时要选择**目标 DBMS**（MySQL、PostgreSQL 等），创建后无法更改。如果需要其他 DBMS，请用**工具 › 复制为其他DBMS**创建新文档。

## 2. 绘制 ERD

### 表和列

- 在空白处**右键 › 新建实体**创建表。
- 用表下方的**添加列**加入列。名称、类型、长度、NN（NOT NULL）直接在表上修改。
- 点击钥匙图标可将列设为主键。
- **双击**列名打开**列信息**。逻辑名、默认值、域类型和说明在这里设置。
- 列有**物理名**（在数据库中创建的名称）和**逻辑名**（供人阅读的名称）。在**视图**菜单中选择显示哪一种。

### 关系

- 点击表边缘的圆点，选择类型（1:N、1:1）和种类（标识、非标识），再点击另一张表。外键列会自动创建。
- **右键**关系线 **› 编辑关系**可以修改基数以及删除、更新时的动作。
- 在同一对话框的**列映射**中，可以更换作为外键的子表列。想让已有的列作为外键时，不必删除关系再重建。

![关系编辑对话框中的列映射](/guide-assets/relationship-mapping.webp)

### 整理

- **自动布局**按关系排列表。旁边的箭头可以选择布局模式（分层、中心辐射、混合）和方向（从上到下、从左到右）。
- 选中多张表后**右键 › 新建分组**，分组会用颜色区分，也可以只查看某个分组。
- **备注**通过右键空白处创建。拖放到表上即可附着到该表。

![选择排列方向](/guide-assets/layout-direction.webp)

### 复制和粘贴

- **右键**表或备注 **› 复制 / 创建副本**。快捷键是 `Ctrl/Cmd+C`、`V`、`D`。
- 复制的内容可以粘贴到同一浏览器**另一个标签页中打开的其他文档**。一起选中的表之间的关系也会带上。
- 用 `Ctrl/Cmd+Z` 撤销误操作。自动布局、粘贴这类一次改动很多的操作，也能一次撤销。
- 按 `Ctrl/Cmd+/` 查看全部快捷键。

## 3. 建立标准 — 单词、术语、域类型

多人绘制多个文档时，同一个东西会被取不同的名字、用不同的方式存储。`email` 在一处是 `VARCHAR(100)`，在另一处是 `VARCHAR(255)`。为了避免这种情况，Crowfoot 为每个工作区设立三种标准。

| 标准 | 回答的问题 | 示例 |
| --- | --- | --- |
| **单词** | 名称中的这一段是什么意思 | `user` → 会员 |
| **术语** | 这个列是什么、是什么类型 | `user_email` → 会员邮箱，域类型“邮箱” |
| **域类型** | 这类值如何存储 | 邮箱 = `VARCHAR(191)`，NOT NULL |

三者都在工具栏的**术语词典**面板中管理。单词和术语在**工作区**标签页，域类型在**域类型**标签页。工作区内的所有文档使用同一套标准。

![术语词典面板的域类型标签页](/guide-assets/standard-panel.webp)

### 推荐的顺序

1. **先创建域类型。** 确定在多张表中反复出现的值的种类，例如邮箱、金额、创建时间。
2. **登记单词。** 即名称中使用的片段及其含义，例如 `user` → 会员、`order` → 订单。不要填写类型。
3. **登记术语。** 填写完整的列名（如 `user_email`）并选择域类型。选择了域类型的条目就是术语。

如果已有填写了类型的词典条目，可以在编辑对话框中用**创建为域类型**把该类型转成域类型。

### 创建列时

开始输入列名时，词典会给出建议。

![列名建议](/guide-assets/term-suggest.webp)

- 选择**术语**会填入完整名称和逻辑名，并在关联域类型的同时填入类型、长度、是否允许 NULL 和默认值。
- 选择**单词**只补全正在输入的片段。在 `user_em` 时选择 `email` 会得到 `user_email`。可以继续输入。
- 列表顶部的**逻辑名**预览当前输入的名称会变成什么逻辑名。

使用域类型的列，名称旁会显示 `D` 标记。

### 需要与标准不同时

列可以在保留域类型的同时使用不同的值。在列信息中修改长度后，对话框会提示哪些属性不同，标记变为 `D*`。用**恢复为域类型的值**可以一键恢复。

如果列名与词典中的术语相同但域类型不同，列信息会显示**词典标准**并建议**应用**。

![列信息中的域类型](/guide-assets/domain-column.webp)

### 修改标准时

修改域类型后，编辑器会询问是否应用到使用它的列。可以逐列预览新值，并选择要更新的列。已决定使用不同值的属性会被跳过。

![应用域类型更改的预览](/guide-assets/domain-propagation.webp)

- 当前未打开的文档不会立即变化。下一位打开该文档的编辑者会看到域类型已更改的提示。
- 应用后可以一次撤销。

### 为已有文档补充逻辑名

从数据库导入的文档常常没有逻辑名。**工具 › 逻辑名**会用词典中的单词和术语补全，例如把 `user_id` 变成“会员 ID”。应用前可以预览结果并进行选择。

## 4. 与数据库互通

在工作区的**数据库**标签页登记连接。如果没有开发用数据库，可以在那里领取免费的数据库。

| 想做的事 | 方法 |
| --- | --- |
| 把数据库结构变成文档 | 数据库标签页的**从数据库导入** |
| 把文档变成 SQL | 编辑器的**生成 SQL** |
| 在数据库中创建文档的结构 | 生成 SQL 对话框的**部署** |
| 修改文档后让数据库保持一致 | **迁移 DDL** — 只针对变化部分的 SQL |
| 把数据库的变化带回文档 | **工具 › 同步数据库** |
| 把手工创建的文档关联到数据库 | **工具 › 连接数据库** |

应用到数据库的更改无法撤销。执行前请务必确认显示的 SQL。

## 5. 查看数据

可以直接查看和编辑已连接数据库中的数据。通过数据库标签页的**查看数据**、编辑器的**工具 › 查看数据**，或**右键表 › 查看此表的数据**打开。

![数据浏览器](/guide-assets/data-tab.webp)

- **数据**标签页：点击表头排序，用条件筛选，并可下载为 CSV。
- **编辑行**：双击单元格进行修改。修改会汇总在底部，点击**应用**后一次性生效。只要有一项失败就全部回滚。
- **SQL** 标签页：直接执行语句。`Ctrl/Cmd+Enter` 只执行光标所在的语句。修改数据的语句需要确认。

![编辑行](/guide-assets/row-edit.webp)

查看数据功能仅 Editor 及以上可用。

## 6. 一起使用

### 成员和角色

在工作区的**成员**标签页邀请个人或团队。

| 角色 | 可以做的事 |
| --- | --- |
| Viewer | 查看 |
| Commenter | 查看、评论 |
| Editor | 编辑文档、连接数据库、管理词典和域类型、查看数据 |
| Owner | 以上全部、管理成员、删除文档和工作区 |

### 同时编辑

多人打开同一文档时，可以实时看到彼此的光标和修改。有人打开编辑对话框的表，对其他人显示为已锁定。

### 对外展示

- **共享**会创建无需登录即可查看的只读链接。可以设置有效期，并可随时撤销。
- **导出**可以生成图片和文档文件（`.crown`）。

### 版本历史

每次保存都会留下一个版本。在**工具 › 版本历史**中可以查看以前的版本、比较两个版本并恢复。

## 7. 检查

工具栏的**校验**会检查文档。它能找出没有主键的表、类型不匹配的外键、不符合命名规则的名称、缺少逻辑名的列等。点击条目可跳转到对应的表。

## 8. 常见问题

**术语词典和域类型有什么区别？**
词典是名称的标准，域类型是类型的标准。`user_email`、`backup_email`、`contact_mail` 名称不同，词典条目各不相同，但三者都使用同一个域类型“邮箱”。

**单词和术语要分开登记吗？**
它们登记在同一个列表中。选择了域类型（或填写了类型）的条目是术语，其余是单词。

**删除域类型后，列会怎样？**
列的值保持不变，只是关联显示为已断开。

**粘贴到其他工作区时，域类型会怎样？**
域类型属于工作区。在其他工作区的文档中，关联显示为已断开，值保持不变。

**什么时候保存？**
停止编辑后会自动保存。也可以用 `Ctrl/Cmd+S` 或**保存**按钮立即保存。
